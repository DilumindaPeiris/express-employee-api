# Upload your project to GitHub
1. Extract this ZIP and open the project folder in VS Code.
2. Follow README.md to run it and review the code.
3. Create an empty GitHub repository with the same name as the folder.
4. In the project terminal, run these commands with your actual details:
```sh
git init -b main
git config user.name "YOUR_NAME"
git config user.email "YOUR_GITHUB_COMMIT_EMAIL"
git add .
git commit -m "Add starter project"
git remote add origin https://github.com/YOUR_USERNAME/express-employee-api.git
git push -u origin main
```
Use an email linked to your GitHub account, including your exact GitHub noreply
address if preferred. Commit genuine improvements after learning the starter.
